# HDL Parser და Simulator

ეს პროგრამა კითხულობს HDL ფაილს, აანალიზებს ჩიპის სტრუქტურას, ასიმულირებს ლოგიკურ ოპერაციებს და CSV ფაილში მოცემული ტესტების მიხედვით ამოწმებს მიღებულ შედეგებს. 
პროგრამა გათვლილია single-bit კომბინაციურ ჩიპებზე და არ მოიცავს bus-ებს ან sequential chips-ებს.

### Built-in Gates

პროგრამა პირდაპირ ახორციელებს ოთხ ძირითად ლოგიკურ ოპერაციას:

* `Nand`
* `Not`
* `And`
* `Or`


### HDL Parser

`FlatSimulator` კითხულობს HDL ფაილს და `PARTS` სექციიდან გამოყოფს გამოყენებულ ჩიპებსა და მათ კავშირებს.

მაგალითად:

And(in1=a, in2=b, out=c);


გარდაიქმნება შიდა ოპერაციად, რომელიც აღწერს, რომ `a` და `b` უნდა დამუშავდეს `And` gate-ით და შედეგი ჩაიწეროს `c`-ში.

თუ გამოყენებული ჩიპი არ არის built-in, პროგრამა ეძებს შესაბამის `.hdl` ფაილს იმავე დირექტორიაში და რეკურსიულად კითხულობს მას.

### Simulator

`evaluate()` ასრულებს parser-ის მიერ შექმნილ ოპერაციებს თანმიმდევრობით და ინახავს თითოეული wire-ის მნიშვნელობას.

### Testing Framework

CSV ფაილიდან პროგრამა კითხულობს:

* input მნიშვნელობებს;
* მოსალოდნელ output მნიშვნელობებს.

შემდეგ ასრულებს სიმულაციას, ადარებს რეალურ და მოსალოდნელ შედეგებს და თითოეული შემთხვევისთვის ბეჭდავს `PASS` ან `FAIL`.

ბოლოს გამოაქვს წარმატებული ტესტების საერთო რაოდენობა.

## გაშვება

HDL და CSV ფაილები მოათავსეთ პროგრამის ფაილთან ერთად ან მიუთითეთ მათი შესაბამისი path.

Terminal-ში გაუშვით:

python hdl_sim.py FullAdder.hdl FullAdder.csv


ზოგ სისტემაში შეიძლება საჭირო იყოს:

python3 hdl_sim.py FullAdder.hdl FullAdder.csv

პროგრამის ზოგადი ფორმატია:
python hdl_sim.py <chip.hdl> <test_vectors.csv>
